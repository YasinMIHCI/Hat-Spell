Recette

La magie se dessine

Un glyphe a trois couches. Le sigil au centre donne l'élément. Les signes autour donnent la forme et le comportement. L'anneau extérieur contient le tout. Le sort part au moment où l'anneau se ferme.

Ce que le simulateur mesure

  • Taille : un grand anneau donne un sort plus puissant.
  • Netteté : un anneau rond et un trait stable font durer le sort.
  • Équilibre : sans signe de projection, le sort dérive vers le côté où les signes sont les plus nombreux.
  • Lacunes : un trou dans l'anneau, même petit, bloque le sort. Une plume sèche laisse des trous.
  • Lisibilité : un signe mal formé rend le sort instable et provoque des ratés.

Gestes

  • Préparez un sort avec l'anneau ouvert, puis fermez-le d'un trait pour le lancer.
  • Un coup de gomme sur l'anneau d'un sort actif l'interrompt.
  • Ajoutez un signe dans un anneau actif : le sort se reconfigure sans s'arrêter.
  • Les sorts partagent le même monde. L'eau éteint le feu, le vent pousse tout, la lumière perce la nuit.

Raccourcis

P plume · E gomme · R tremper · N nuit
